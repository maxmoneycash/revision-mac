# Revision for Mac

A second look before you ship. Compare UI screenshots, annotate changes, and export precise feedback for your coding agent.

This repository contains the public website, release downloads, and issue tracker. The application source is maintained separately.

## Preview

Download the latest release. Requires macOS 14 or later, Apple Silicon or Intel. This developer-signed preview is not yet notarized by Apple. macOS may block it; wait for a notarized release if preferred. See release notes for status.

Includes a seven-day feedback-export trial. Afterward you can still open, compare, edit, and save projects. Paid license checkout is not open yet.

## Workflow

1. Add baseline and current screenshots of the same screen.
2. Compare side by side, with a wipe, overlay, or difference view.
3. Mark regions and add Change, Keep, or Restore instructions.
4. Export a review bundle, then give the folder to your coding agent and ask it to read REVIEW.md.

Revision doesn't automatically capture screens, modify your code, or align images. It processes images locally.

## Feedback

Open an issue with reproduction steps and your macOS version. Don't include license keys or sensitive screenshots.
